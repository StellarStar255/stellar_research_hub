# v0.2.0 — 网页版支持 Codex 与自定义模型

网页版新增 AI 后端选择，可在侧栏切换 Claude Code / Codex，并填写任意有权限使用的模型名。留空使用对应 CLI 的默认模型。浏览器会记住选择，历史对话恢复其后端和模型。

- Codex CLI 接入：支持 JSON 事件、工具步骤、会话续接、停止和错误显示。
- 切换后端时携带已有对话；实验结果自动回传仍使用该对话选择的后端和模型。
- 受限 MCP 工具支持读取 PDF 文字及页面图、图片、笔记和实验文件；主题支持搜索、引用查询、确认计划后导入论文及写报告。
- Codex 使用只读沙箱并关闭 shell；实验仍由用户点击「运行」。
- 新增 `RESEARCH_AGENT_PROVIDER` 默认后端配置；`RESEARCH_AGENT_MODEL` 可设置默认模型。
- 补齐网页版 FastAPI / Uvicorn 依赖。

## 使用

安装应用依赖后启动 `./start.sh`，在侧栏选择后端并填写模型名。使用 Codex 前先安装新版 Codex CLI 并运行 `codex login`，需要支持 `--ignore-user-config` 的版本。

模型可用性取决于 CLI 和账号权限。Codex 集成不加载用户 `config.toml`，以隔离外部 MCP、hooks 及其他设置；思考强度当前使用默认值，没有新增强度选择器。Qt 桌面版仍使用 Anthropic API。
